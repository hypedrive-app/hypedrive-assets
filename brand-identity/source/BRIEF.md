# Shared brief — Hypedrive UI kit polish (read fully before working)

Product: Hypedrive, an Indian platform where brands send products ("drops") to creators, who post honest reviews on Instagram/YouTube and get paid in ₹. Static HTML design system generated by Python; renders in `~/Downloads/hypedrive-wordmark/BRAND/ui/`.

Owner rules: `~/Downloads/hypedrive-wordmark/BRAND/HANDOFF.md`. Skills to apply: `~/.claude/skills/ui-taste/reference/{polish,craft,anti-slop-craft,distill,mobile-controls}.md`.

## Hard rules (the owner rejects anything that breaks these)
- **No bloat.** Polish = fewer things done better. Never add badges, overlays, chips, legends, counters, captions, support codes or decorative bars that don't carry real info. If something you see is decoration, remove it. Modern, calm, premium (Linear / Vercel / Apple).
- **Crisp edges.** The owner's display has a fractional DPR (1.8125). In-flow surfaces (cards, rows, panels, inputs) use a real CSS `border: 1px solid var(--hd-edge)`, never a box-shadow ring and never SVG strokes. Squircle script (`squircle.js`) is limited to `.x-go, .x-disc`; don't change it.
- **Buttons:** primary = flat deep Cobalt (`--hd-accent`), no gradient, no coloured glow, faint top highlight + 1px neutral contact; secondary = white + 1px hairline + soft contact; ghost = text; sizes 36/44/52, radius 10/12/14.
- **Icon containers** = white tile + 1px hairline + soft two-layer shadow, glyph in the meaning colour (`.x-tile` classes). No tinted or grey slabs behind icons.
- **Tints** only through tokens (`--hd-*-subtle` backgrounds, `--hd-*-strong` text). Badges/chips tinted, no border, with a solid status icon.
- Icons: Nucleo UI Outline 18 via `ic(name)` idle; exact Fill 18 twin via `ics(name)` active. Names in `NMAP` (uikit.py) — don't edit NMAP; list any new names you need.
- Radius scale 4/6/8/10/12/14/16/24/full; 4px spacing grid; Bricolage for headings and hero numbers, Geist for UI; ₹ no space, Indian grouping, U+2212 minus; no emoji, no gradient text, no uppercase tracked labels; people photos never larger than 72px.
- Data must agree: Glow serum ₹1,240 · 84/120; Night cream ₹990 · 42/100; Clear skin set ₹980 · Full 60/60; Daily cleanser trio ₹640 · 18/90; all Lumen Labs; HDFC ••6093; Riya Sharma = `people/women-68.jpg`; today Fri Nov 20 2026.
- Light AND dark must both be excellent.

## ADDENDUM 2026-11-20 (late) — the approved language. The owner flags anything off it as "ugly".
Everything the owner called "ugly" today shared the same faults:
- controls that were oversized
- states signalled three ways at once (tint + border + coloured text + check)
- grey slabs used as backgrounds
- bordered keyboard chips
- decorative extras such as histograms
- tick marks placed inconsistently
- heavy discs
- dead space
- duplicated information

Apply this language everywhere:

- **Sizes**
  - Controls are 36, 40 or 44 tall.
  - Menu rows are 34 tall with 14px text, 16px muted glyphs, and an 8-radius inset hover at fg 6%.
  - List rows are 48–68 tall.
- **Selected states**: use ONE signal.
  - Chips and toggles: accent-subtle fill, no border, strong text.
  - When a toggle is off, show a white surface with a hairline, muted text and a greyed glyph.
- **Ticks**: always trailing (on the right), never leading, in menus and lists.
- **Shortcuts in menus**: plain text, fg-subtle at 12.5px, with no keycap borders.
- **Status glyphs**:
  - Use the solid twin (ics) bare, or on a WHITE 40px tile with a hairline.
  - Never use a big solid coloured disc.
- **Buttons**
  - Use the tactile cobalt finish (xlead "BUTTONS v-final") and the white secondary. Never override their shadows.
  - Use a small secondary for row actions.
  - Use link-text only for "learn more" style links.
- **Photo cards**: full-bleed, as in product card v5 in xd.py.
  - The photo stays full colour.
  - Text sits at the bottom on one scrim.
  - Status chips are solid.
  - No top wash.
- **Dates**
  - Use 36px circles.
  - Today is shown as accent text with a dot.
  - Out-of-month cells are blank.
  - A range is one continuous band.
- **Counters and progress**: use a hairline 3px bar plus "N of M" in tabular numerals, and say it once.
- **Text sizes**
  - Titles: 15/600 in rows, 17–20 on cards.
  - Body: 14/20.
  - Meta: 13–13.5 muted.
- **Dark mode**
  - Every edge stays visible.
  - Tints come from the tokens.
  - Text on a tint uses the -strong colour.
- NO TINTED BORDERS (owner, 2026-11-20): a tinted surface (notice, chip, selected card, badge) is fill-only. Borders are neutral hairlines (--hd-edge), or none at all. Focus rings and the error border on an input are the only coloured edges.

## MOBILE SCREENS REDESIGN (2026-11-20) — owner: "every page of the mobile app is ugly"
Apply the ADDENDUM language and every owner rule to real app screens (390×844):

- Tab bar: a hairline top edge, 24px icons, 11/560 labels, active = solid accent glyph + label.

- DIALOGS: UI-font title at 16/600, the consequence in bold body text, a hairline footer, 36px Cancel + action. No icon tile. Danger is a true red (#d92d20 / dark #e5484d), not orange.
